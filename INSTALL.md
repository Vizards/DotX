# Install or update DotX

- **First installation:** Follow the [setup skill](apps/desktop/skills/setup/SKILL.md) in local Codex to set up this Mac and your DotX service.
- **Adding another Mac:** Follow the [join skill](apps/desktop/skills/join/SKILL.md) in Codex on that Mac to join your existing service.
- **Updates with local Mac access:** Follow the installed Desktop update skill ([source](apps/desktop/skills/update/SKILL.md)).
- **Updates coordinated through DotX Remote:** Read `get_instructions(goal="update")` ([Remote update skill](apps/server/skills/update/SKILL.md)) before delegating work to local Codex.

For updates, the target Release's notes and `release.json` provide version-specific requirements; the update skills explain how to apply them.
